# 文案初稿 V1

> 第一版完整文案，保留最初的选题切入、案例顺序和表达方式，用于展示内容从初稿到成稿的演进过程。本页是创作存档，其中的判断与表述不作为最终测评结论；公开结论以[作品集发布版](video-script.md)和[测试记录](test-record.md)为准。

雷猴啊，朋友们，你有过因为不了解电脑，被复杂的系统操作绕晕的经历吗？电脑最烦人的事，往往都不是什么大事，C盘红了，文件乱了，东西找不到了，学习资料一大堆懒得整理，每件事都很烦，那如果有一天，这些事情都能交给AI呢？诶！有这么一款agent，号称：24小时的AI管家，我愿意称它为：比懂我的人更懂电脑，它就是Marvis--马维斯。

​	至于能不能比懂电脑的AI更懂我，咱们直接上手试。

​	像清理C盘，寻找指定文件这些需求清楚的任务，AI干起来都简简单单。但最让我们头疼的问题是电脑里那些连在哪都不知道的东西，比如说当我们找文件的时候，不知道文件放在哪了，甚至连文件名都忘记了，只知道大概讲了什么，那咋办？

我们把这个问题给到马维斯，我们之前是不是讨论过大学生市场，最后为什么没做？这个问题是不是特别无厘头？但是马维斯他竟然真的可以根据我们的模糊不清的意思找到，你看他说真实对话记录里没有这一段讨论。但是在本地确实有一套对应的资料，就是我们聊的关于大学生市场的问题。并且没做的原因也给我们标出来了。如果换做我们自己去回想，去找的话，甚至我们可能连他在哪个盘，文件名字叫什么都不一定能找到，并且我们也需要一个个文件的去翻，查看问题到底出现在哪里是什么原因。马维斯就能给我们做到快速定位，并且给出我们要问的问题的总结。那他能不能在文件名字都是混乱的情况下，帮我们找到我们想要的？我们问他，我是不是存过一份讲休息也会像完成任务一样的资料？结果他真的可以找到。这是一个文件名跟内容毫不相关的文件，甚至是图片格式的，它都能帮我们找出来。相当于基于我们的电脑文件，作为知识库，来回答我们的问题。而当你在根目录新建文件后，怕他不能自动找到，也可以直接点击设置，找到授权设置，把文件夹授权给他就可以了，而如果你忘记这一步了，只要和他聊过一次关于这个文件夹里面的对应知识，马维斯都能根据长期记忆去检索内容，找到这些信息。

​	那我开始理解管家这个词了，相比那些解决高深复杂大问题的AI，马维斯更希望解决的，是那些隐藏在我们身边常见的小而麻烦的电脑小事。

​	既然这样，那我们来尝试一些步骤复杂并且更加贴近我们生活的任务。比如我和马维斯说。刚刚我用QQ给自己发了今天上课的课件和笔记，还从手机上给电脑上传了今天上课拍的题目。你帮我放到d盘里，弄个学习文件夹保存好。并且最好分别整理一份总结给我。笔记是需求分析的，图片是mysql这门课的。完成后提醒我3分钟后记得复习你整理好的东西。在你提醒后，需要打开需求分析的总结和笔记，让我使用电脑的时候可以直接复习。

​	经过一段时间的等待，马维斯就生成了一个新的学习文件夹，文档也分好了，并且用结构树的形式发给了我们，分别是需求分析跟MySQL，里面的笔记、课件、图片整理的很不错，同时他也给我们设置好了定时任务。我们不需要任何的操作，当这个时间到的时候，它会自动打开这个文档。我们直接开始复习就行了。但是他不会直接通知我们，而是在电脑里直接完成相应的任务。不过他们的总结没有放进来，而是默认在c盘，我算知道c盘怎么莫名其妙爆了。我们告诉他把这两个都分别放到文件里面，并且给他那张截图，它也能够做图片识别，确定我们模糊不清的需求，还是比较聪明的。再让他做一份教学文档教我们，放在d盘里面，等我们学习的时候，就直接可以用了。把上课摸的鱼轻松补回来了。这个任务没有一步很难，但对于嫌麻烦的懒人党来说简直是福音！

​	管家名头有了，那24小时的说法从哪里来呢？诶！如果是坐在电脑前操作的话，他仅仅是帮你省去了找这些操作，完成这些的步骤的时间。但是你还需要坐在座位上等待他完成，那如果你可以在手机上通过和马维斯交流，在电脑不在身边的同时完成需要使用电脑的任务呢？

​	 想象一下，你刚刚下课，做完笔记，拍完照片，老师还把一堆ppt课件和作业发给你，你第一时间大概率去不会整理，而是去吃饭，或者休息，懒得去马上整理这些东西。而等到晚点来看的时候，你要翻笔记、找照片、看ppt。这些每一步都不复杂但是会消耗你很多的时间和精力，去整理翻看意义不大但必须完成的任务。而当你使用马维斯后，你只需要把东西一股脑的发送给电脑，然后再通知马维斯完成这个任务，等你吃完饭或者休息回来时，就会发现以前需要不停打断你思路的活，已经全部完成了，甚至可能比自己做的更好。这个任务本身没有任何一步很难。但是它有七八个步骤，而且每一步都很烦。如果能轻松完成，就像一天24小时凭空多出了一个小时去完成这个任务，并且还省了不少精力，用来更好的去学习，而不是先整理一遍资料，弄完了，刚开始学习就累了。

​	当你结束工作或者学习，准备使用电脑放松一下时，如果是以前，你需要打开各种软件，完成一系列准备。而现在，你可以在手机上让马维斯把这些工作完成。比如说，我马上要到家了，帮我把双人成行这个游戏准备好，我到家就要玩。它就会把游戏提前给你打开，如果你没更新，他还会贴心的新帮你先更新，还能根据你想玩的游戏和电脑的配置，推荐好合适的电脑设置，而你需要做的就是。当你坐在电脑前时，直接就可以享受游戏的快乐时光了。

​	而要达到这个效果，只需要电脑和手机同时下载马维斯，登录同一个账号，就这么简单，就可以在手机上指挥马维斯在电脑里干活了。甚至还能通过手机实时监工，看看电脑怎么样了。在手机上通知，不用在电脑旁就可以完成电脑上基础，但是耗时耗精力的任务，让操作没有距离感。

​	为什么马维斯会比其他AI更加懂你的电脑呢？因为它是操作系统层级 AI 助手，不只是呆在聊天框里面，它可以读取底层的硬件，调用系统管理本地文件，说白了就是直接嵌入系统的Agent管家，好比给系统配上了大脑和手脚，帮助你更好的掌控自己的电脑。就像公司老总身边的专业助理团队，帮助老板更好的管理公司。而其他的agent大部分都还停留在应用层，虽然也能干，但是在管理你的电脑这方面，马维斯更加的方便。

​	这时候有小伙伴要问了，他这么懂我的电脑，会不会把我的工作内容数据泄露出去？

​	而如果你需要做一些保密性更强的工作，同时又想使用ai，还不想去完成复杂的配置工程，那么马维斯的本地模式或许很适合你，只需要点击他。就会在你电脑上配置好本地模型，在本地工作。唯一的问题就是，需要你电脑的硬件足够过关，而能不能顺利带的动本地模型，问马维斯就好啦，他大概率会比懂你的人更懂电脑！

​	不管你是在电脑或手机上操作，系统都会贴心的调出相关按键，既节省寻找功能与按键的时间，又支持我们亲自操作，点击按钮，让我们更加的放心，轻松达到目的的参与感和成就感满满，这个设计是我觉得特别棒的。真的像是一位贴心的管家，在接到你的命令之后，把所有的信息调查好，并且预备好，然后摆在你面前，只要你同意，并做出选择，他就会按照你的想法去执行。这样你能看得见，放得下心，并且也不用花费很多的时间在这种比较繁琐的事情上。

​	我觉得他和其他AI相比的亮点是。其他的AI软件一直在想办法解决更大更难更复杂的问题，而在这些小而繁琐但却重要的操作问题上，马维斯做出了自己的特色，覆盖了生活里日常电脑使用的细节方面。而影响我们电脑使用体验的，正是这些藏在生活里各方面繁琐的操作问题。真的能在生活里，给我们节省不少的精力和时间，放到更重要的事情上，而这正是我们拥抱ai的意义。

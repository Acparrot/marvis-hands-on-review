# 《C盘爆红、文件失踪？我让 AI 管家接管电脑日常任务》

[返回主页](../README.md)

> 本稿为约 8—10 分钟的中长视频逐字稿。括号内为画面、剪辑或证据建议，不读出。

## 逐字稿

（画面：C 盘容量红条、杂乱文件夹、多个应用窗口快速切换）

你用电脑最烦的时候，是不是往往都不是遇到了什么大故障？

C 盘突然红了，文件不知道放到哪里了，上课收到一堆笔记、课件和照片，懒得整理；想玩个游戏，又要先打开平台、检查更新、调设置。

每一步都不难，但每一步都在消耗注意力。

那如果把这些琐碎的电脑任务交给 AI，会发生什么？

（画面：Marvis 首页，字幕“你的 24 小时 AI 管家”）

我最近实测了腾讯的 Marvis，中文名叫马维斯。官方把它定位为“24 小时 AI 管家”。和只在聊天框里给你答案的 AI 不同，它想做的是直接理解你电脑里的文件、调用应用、查看硬件，甚至完成系统操作。

听起来很美好，但“能调用功能”和“能完成真实任务”之间，还隔着很长的一段路。

所以这次我不测它能不能“打开一个设置页”，而是丢给它三组更接近真实生活的连续任务。

### 第一关：只记得文件讲了什么，还能找到吗？

（画面：用户问“我们之前是不是讨论过大学生市场”）

普通的电脑搜索，要么要你记得文件名，要么要你大概知道它在哪个文件夹。偏偏人的记忆并不是这么工作的。

我可能只记得，以前好像讨论过一个大学生市场项目，最后没做，但文件叫什么、放在哪个盘，全都不记得。

我把这个模糊问题原样交给 Marvis。

（画面：文件列表和时间线结果）

它先告诉我，真实对话记录里没有这段完整讨论；然后继续去找本地文件，找到了一组从 3 月到 6 月的记录，包括市场讨论、用户调研、会议纪要和项目复盘。

它不只是把文件列给我，还整理出了整条时间线：前期做了调研，后面发现单个付费用户的获客成本超过预算，而愿意按月付费的用户又不够多，所以项目暂停。

这一轮，它确实找到了我只记得“意思”的资料。

我又把难度加了一点：我是不是存过一份讲“为什么休息也会像完成任务”的资料？

（画面：文件名与内容无关的搜索结果）

这份文件的名字和内容没什么关系，但 Marvis 还是定位到了它，并提炼出其中的核心观点。

不过我把问法改成“我在哪里讲过”以后，它又优先去找历史对话。所以这里也有一个很典型的 Agent 问题：用户说的是一句普通话，AI 却要先判断到底应该去搜本地文件、历史对话，还是长期记忆。

对我来说，它如果能直接显示“这条结论来自本地文件”，会比只给答案更让人放心。

### 第二关：一句话里塞入七八个步骤

（画面：完整的学习资料整理指令）

下一个测试更接近真实生活。

我告诉它：QQ 里刚刚传进来了三周需求分析笔记，还有一组 MySQL 课堂照片。请按科目放到 D 盘学习目录，分别做总结，三分钟后提醒我复习，并自动打开需求分析总结和笔记。

这里没有任何一步特别难，但它要跨过文件查找、内容识别、文档生成、目录管理、定时任务和应用打开。这才是测试 Agent 的地方：不是看它会不会说，而是看它能不能把这些步骤接起来。

（画面：两份总结、目录结构、定时任务）

结果是，它读取了三周笔记，识别出 MySQL 照片里的查询练习和视图题，生成了两份摘要，还建立了三分钟后打开文件的任务。

目录也分成了 MySQL 和需求分析，后面还补了一份 MySQL 教学文档。

但问题也在这里出现了。

第一次生成的两份总结，默认留在 C 盘的 Marvis 工作区，而不是我指定的 D 盘。我又追加了一次指令，才把它们放进对应目录。

而且时间到了之后，文档确实打开了，但没有出现我预期的醒目提醒。

所以这个任务我会给“部分成功”，而不是满分。它把最费神的步骤做了，但还没把最后的交付感做完整。

这也是我认为系统级 Agent 最容易被忽略的问题：“我执行了”和“你现在可以直接用了”，不是一回事。

### 第三关：到家前，能不能先把游戏准备好？

（画面：Marvis 要求用户确认游戏已登录）

如果 AI 只能在我坐在电脑前时帮我点几下，那它只是省了操作时间。但如果它能在我不在电脑旁时接收任务，那么节省的就是等待和注意力。

我尝试让 Marvis 提前准备《双人成行》。它找到了游戏，检查窗口状态，并在需要登录时让我确认。最后，游戏成功进入启动状态。

（画面：《双人成行》启动界面）

这里我不会说它“全自动替我搞定了一切”，因为登录和应用内状态确实需要人工介入。现有截图也不足以完整证明手机到电脑的整条跨端链路，所以我只把“电脑端成功执行”算进结果。

然后我让它检查这台电脑能不能带动游戏。

（画面：读取配置、掉帧诊断报告）

它读出了 i5-12600KF、RTX 4060 和 32GB 内存，判断硬件足以运行，然后把掉帧问题指向了电源模式、后台程序和游戏内设置。

它没有直接默默改掉所有设置，而是让我选择要不要优化。这会让流程慢一点，但我反而觉得必要。

因为当 AI 只给你一段文字时，答错了最多是答错；当 AI 真的能关程序、改设置、移文件时，它就必须把权限和风险说清楚。

### 那本地模式呢？

（画面：组件安装提示、本机存储空间）

Marvis 官网还主打一个很重要的点：本地模式使用端侧大模型，文件不上传。

但这一部分，我的测试只进行到组件安装提示和硬件、存储检查，没有完成模型部署，也没有做断网对话、本地文件解析和网络流量核验。

所以更准确的说法是：官方提供了本地模式，但这次我没有完成对“完全本地”的独立验证。

这不是咬文嚼字。如果一个功能的核心卖点就是隐私，那么“看到开关”和“完成验证”之间，必须画出清楚的线。

### Marvis 真正的价值是什么？

（画面：三组任务的结果卡，成功 / 部分成功 / 未完成验证）

用完之后，我对“AI 电脑管家”的理解，反而没有变成“它什么都能做”。

它最有价值的地方，是能处理那些单步不难，却要不断切换窗口、找入口、记路径的任务。

找一份只记得内容的文件；把一堆课件、笔记和照片变成可复习的资料；让 AI 读取硬件、找到设置、给出可执行的建议。

这些事情没有一件足够“高大上”，却正好是每天在消耗我们的事。

它和普通聊天 AI 的差别，也正在这里：普通 AI 告诉你“可以怎么做”，Marvis 尝试往前走一步，真的帮你做。

但只要它开始“做”，就必须回答另外几个问题：东西放到哪里了？任务做到哪一步？哪些动作需要我确认？如果做错了，能不能撤销？

这些问题，才决定一个系统级 Agent 是新鲜的演示，还是能长期使用的工具。

所以我这次的结论是：Marvis 已经能够在一些真实任务里替用户走完多个步骤，尤其是模糊找文件和跨应用任务。它还不是一个可以完全放手的管家，但已经让“和电脑说人话”从聊天的噯头，开始变成一个可用的操作入口。

下一步，我更想看的不是它又多了几个功能，而是它能不能把任务状态、产物去向和安全边界做得更清楚。

因为一个真正好用的 AI 管家，不只要能干活，还要让你随时知道：它做了什么，为什么这么做，以及它什么时候应该把决定权交还给你。

（画面：回到 Marvis 首页，出标题卡“能做事，更要让人放心”）
